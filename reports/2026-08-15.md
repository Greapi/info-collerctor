### 2. 美团：KDD 2026 论文、KDD Cup 冠军与搜索 3.0 实践

美团技术团队发布 [KDD'26 美团学术论文精选及 KDD Cup'26 DataAgents 赛道冠军思路解读](https://tech.meituan.com/2026/08/13/KDD-2026-meituan-papers.html)，共有 8 篇论文被 KDD 2026 收录。要点包括：

- **MTFM**：可扩展、免对齐的工业推荐基础模型，基于 Transformer，将跨域数据转为异质 Token，并引入多场景用户级样本聚合、Grouped-Query Attention、Hybrid Target Attention 等，已作为统一基座推荐大模型全量替换独立精排。论文见 [arXiv](https://arxiv.org/abs/2602.11235)。
- **CDRRM**：对比驱动的评分准则生成与奖励建模框架，仅用 3 千样本使未微调模型超越全量微调基线。论文见 [arXiv](https://arxiv.org/pdf/2603.08035)。
- **LocalSearchBench**：本地生活服务智能体搜索评测基准，覆盖 9 城、6 大服务品类、900 道多跳问答，发现当前主流 LLM 推理模型普遍存在信息完整性、可信度不足等问题。论文见 [arXiv](https://arxiv.org/abs/2512.07436)。
- **JTransNet**：联合广告拍卖中的匿名性与确定性分配方案，已在美团零售核心业务场景全量上线。论文见 [ACM DL](https://dl.acm.org/doi/epdf/10.1145/3770855.3818370)。
- **UME**：统一元泛化框架，用于跨域 ETA，采用双分支网络与超网络元学习，并通过知识蒸馏弥合特征缺失。论文见 [arXiv](https://arxiv.org/abs/2606.00979)。
- **GRAD**：可扩展的自动竞价基础模型，以动作混合专家模块探索多样化竞价行为并结合因果 Transformer。论文见 [arXiv](https://arxiv.org/abs/2508.02002)。
- **HMAF**：分层多坑位 GD-RTB 分配框架，按“规划–校准–执行”统一优化曝光分配，平衡短期收入与长期合约交付。论文见 [arXiv](https://arxiv.org/abs/2606.09896)。
- **MTGenRec**：生成式推荐模型分布式训练框架，相比 TorchRec baseline 训练加速 1.6–2.4 倍，8 卡扩展到 128 卡近似线性。论文见 [arXiv](https://arxiv.org/pdf/2505.12663)。

KDD Cup 2026 DataAgents 赛道中，大众点评技术部获得冠军与季军。团队迁移“问点仔”Agent Harness 能力构建 Agent 运行时，支持 SQL、Python 等工具选择与执行，并构建多模态视频理解子智能体和文档 ETL 子智能体。冠军方案代码已开源：[zhezh/kddcup2026_champion](https://github.com/zhezh/kddcup2026_champion)。

与此同时，美团搜索团队发布 [美团搜索3.0：LLM 语义表征在排序模型的探索与应用](https://tech.meituan.com/2026/08/20/01-meituan-Query-3.0.html)。该文介绍 2025 Q4 到 2026 Q2 的三期实践，一期、二期均完成全量上线：

- **一期（验证可行性）**：轻量 LLM 全参微调，新增 `<|query|>`、`<|item|>`、`<|qi|>` 三个特殊 Token；训练样本 3,000 余万条，下单:点击未下单:未点击=1:3:6；提取 64 维语义表征并注入精排。线上 2025/9/18–10/1 期间，大盘搜索支付订单 +0.20%、服务零售订单 +0.27%，长尾 NDCG@5 +2.21pp。局限包括缺商品侧、全参微调成本高、目标偏点击、推理效率低。
- **二期（商家精排表征系统性升级）**：训练数据扩展为五元组，共 2,766 万条，以同请求曝光未点击作为难负样本；采用“精简信息陈述+总结引导”Prompt，中等参数 Embedding 模型 + LoRA；表征提取改为独立序列 + 可学习向量，一次 Forward 处理五路输入；降维采用 MRL-E；损失函数从 BCE 转为 InfoNCE 对比学习，并引入 Triplet Loss。消融显示引入 Triplet Loss 后 Q2I-Click-AUC +4.85pp、Q2I-Order-AUC +11.02pp。

## 趋势与判断

1. **Agent Skills 正在形成跨模型、跨工具的通用能力层。** 从 GitHub 上多个 awesome 聚合仓库、Anthropic 社区插件市场到 DeepSeek Harness 插件列表，均以技能、插件形式封装可复用能力。兼容 Claude Code、Codex、Gemini CLI、Cursor 等成为普遍诉求，意味着上游模型差异正在被统一的 Agent Skills 标准部分抹平。

2. **本地优先与隐私友好成为 AI 知识管理的新卖点。** claude-obsidian、openhuman、Analogy for Obsidian 等均强调本地、Markdown、无隐私风险。这一趋势与“个人第二大脑”需求结合，可能推动本地 RAG 和 MCP 工具的进一步普及。

3. **AI 编程工具进入整合期。** Cursor 被 SpaceX 收购并加入 SpaceXAI，a16z 明确将其描述为“AI lab/token creator”。这意味着头部 AI 编程工具不再只是 IDE 或代理，而是与模型研发、算力布局深度绑定。同时，社区对 OpenAI Codex 重置力度、Opus 5 体验变差等讨论显示，产品策略与用户感知之间存在张力。

4. **基准与成本并重，效率竞争成为模型公司的新叙事。** Grok 4.6 在 CursorBench、ARC-AGI 上不仅展示分数，还反复强调单位任务成本优势；DeepSeek 也更新峰谷定价。这表明单纯能力领先已不足以建立优势，单位智能成本正在成为关键决策变量。

5. **中国技术团队在推荐、搜索与智能体竞赛中的工程深度显现。** 美团 KDD 论文覆盖推荐基础模型、自动竞价、生成式推荐训练框架等完整链路，且 JTransNet、MTGenRec 等已全量上线；KDD Cup 冠军方案则验证了将 Agent Harness 能力迁移至数据代理竞赛的可行性。
