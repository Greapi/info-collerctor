今日概览

今日科技领域聚焦多个重大进展：AI 领域，OpenAI 下一代模型 Astra 内部版本攻克 10 道数学与理论计算机科学重大难题，引发行业震动；在应用端，围绕大模型编程、AI 鉴图、本地部署等出现大量新工具与新讨论。基础设施方面，硬件钱包 Coldcard 黑客事件持续恶化，损失或达 8860 万美元。同时，Linux 桌面在北美市场份额历史性突破 10%。特斯拉 CEO 埃隆·马斯克在 X 上动态频繁，涉及 Grok 模型能力、SpaceX 年度第 90 次发射及多项社会话题评论。

重点事件

1. OpenAI 下一代模型 Astra 取得数学领域重大突破

OpenAI 于官网公开了下代模型 Astra 的内部版本细节，其解决了数学与理论计算机科学领域的 10 个重大开放难题，涵盖几何学、密码学、复杂性理论等多个分支。具体成果包括：证明了“非索菲克群”的存在、反驳了 Connes 刚性猜想、在高维球体填充和电路复杂性方面获得了更优界限等，所有证明均附带精简证书与思维链演示。萨姆·奥尔特曼随后发文“团队人类”。（来源：Ten advances in mathematics and theoretical computer science，RT Sebastien Bubeck）

2. Karpathy 展示 LLM 长程任务生成能力

Andrej Karpathy 分享其使用 Anthropic 的 Opus 5 模型，在约 10 美元开销、100 万 token 的预算下，耗时约 2 小时，自主编写 5500 行代码，生成了用于程序化三维动画渲染《指环王》首段文字的脚本。Karpathy 认为这标志着 LLM 评测正从过去“画一辆自行车上的鹈鹕”等简单测试，向大规模自定义世界生成进阶。同时他指出，LLM 目前尚无法原生感知视频或实际游玩游戏，这使其在审计自身输出成果时存在显著短板。（来源：Karpathy’s Pelican）

3. Coldcard 钱包被盗事件持续恶化

加密货币硬件钱包 Coldcard 近期遭遇的黑客攻击事件持续发酵，分析显示此次攻击造成的损失可能已达 8860 万美元，引发社区对硬件钱包安全性的广泛担忧。（来源：The Coldcard Disaster Gets Worse: The Hack May Have Reached $88.6M）

4. Grok 模型获马斯克大力推介

埃隆·马斯克宣布 Grok 现可分析任意视频，用户上传后即可提问，并同时展示了 Grok Imagine 的图像生成能力。此外，他引用第三方评价称，Grok 4.5 在综合考虑速度与成本时，表现为帕累托最优，并转发了开发者关于 Grok 4.5 生成了函数简短、嵌套浅的“最漂亮 C 语言代码”的评价。（来源：Grok can analyze any video，Grok Imagine，Grok 4.5 is Pareto #1，Cool）

5. SpaceX 完成 2026 年第 90 次猎鹰发射

SpaceX 在 8 月 2 日于范登堡成功发射一枚猎鹰 9 号火箭，搭载 24 颗星链卫星，其助推器 B1081 完成第 26 次飞行并成功回收。这是 SpaceX 本年度第 90 次猎鹰系列火箭发射任务。（来源：RT X Freeze）

趋势与判断

1. AI 能力迈向超越人类智力极限的新前沿

今日多条动态均指向 AI 能力的关键性跨越。OpenAI 的 Astra 模型在纯数学领域证明了此前悬而未决的难题，这是从语言生成、代码编写向深度科学推理的重大延伸。与此同时，Karpathy 的演示则展示了 AI 从零生成复杂、大规模创意作品的成熟能力。马斯克转发的一则评论概括了这一趋势：“AI 会越来越多地完成更困难的任务……我们一开始会惊叹，然后会习以为常。”（来源：RT Yun-Ta Tsai）

2. AI 驱动开发的生态正在爆发与重塑

开发者工具与社区围绕 AI 编程形成了两个鲜明趋势：一是从模型到基础设施的深度整合，如 Claude Code 中转服务在 29 天内即吸引 145 个用户并消耗 306 亿 token，且社区为此开发了防止 Mac 休眠的心跳脚本（来源：历时 29 天，145 个用户，306 亿 token 调用量！，写了两个脚本，Claude Code 干活时 Mac 不睡觉）；二是 “氛围编程”成为常态，如完全不会 Go 语言的开发者借助 Codex 仅通过撰写 README 和测试就开发出微信机器人（来源：根本不会 go 语言，做了个给微信 clawbot 发消息的机器人）。同时，关于开源项目是否应利用 AI 加速开发引发了社区讨论（来源：似乎开源项目作者不知道/不想利用 AI 来加速自己的开发？）。

3. 多模型协作与垂直场景应用的探索增多

将多个大模型组合完成特定任务成为新的实践方向。例如多模型 AI 鉴图工具“明眼社”通过集成 GPT-5.6、Qwen3 VL 等交叉判断图片是否为 AI 合成（来源：做了个多模型 AI 鉴图小站）；BEAM 项目则让三个 Agent 竞猜财报后股价涨跌，用于对比模型金融预测能力（来源：写了一个 agent 赌财报网站）。这反映出社区正从单一模型应用转向构建有特定目标的 Agent 系统。

4. 云端大模型价格战冲击本地部署性价比

随着云端大模型服务价格持续走低，有观点明确指出，利用 Mac 统一内存本地部署 32b 参数模型已丧失成本优势（来源：云 llm 越卷越便宜）。这与此前本地运行模型的热潮形成对比，预示着个人和中小开发者可能会进一步倒向云端推理服务。

值得继续关注

  • OpenAI Astra 模型正式发布：此次仅是内部版本展示，其何时正式推出、在通用任务上是否也将有类似跃升将是后续关键。
  • Coldcard 黑客事件后续：8860 万美元的损失是否会引发更广泛的硬件钱包安全审查，以及事件根因的最终披露值得关注。
  • Claude Code 的爆发式增长：其社区与生态扩展速度极快，看门狗等周边脚本的出现表明用户在将其用于高时长、高价值任务。
  • 本地大模型部署的价值重估：在云端 API 价格持续下降和上下文压缩技术（如 5 亿 token 插件）并行的背景下，开发者的计算归属选择将成为持续的讨论点。
  • AI 生成内容的可信度与识别：随着“明眼社”等工具的兴起，以及知乎充斥 AI 生成文章的讨论（来源：知乎里一眼望去都是 gpt 生成的文章），如何界定和鉴别 AI 生成内容正从技术问题演变为社会价值判断问题。
