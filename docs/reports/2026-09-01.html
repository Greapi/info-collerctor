终端与开发工具

  • herdr 终端复用器实践指南：少数派介绍 Rust 编写的终端复用器 herdr，类似 tmux/Zellij，可自动识别 Claude Code、Codex、Cursor CLI、Grok Build、Antigravity CLI、Pi、OpenCode 等 CLI Agent，并在左侧栏标注 Blocked / Working / Done / Idle 四种状态；支持 macOS、Linux、Windows，快捷键沿用 tmux 的 Ctrl+b 前缀，Ctrl+b g 可唤出 Agent 快速跳转面板。官方提供 herdr --skill，可让主力 Agent 自行切分屏幕、调度多模型。需注意：detach 只保证关窗或 SSH 断线后继续运行，断电或系统重启后普通进程仍会被回收；只有安装官方 herdr integration 的受支持 Agent 才能在重启后恢复会话上下文。（来源：从分屏到放牧 Agent：herdr 终端复用器实践指南）
