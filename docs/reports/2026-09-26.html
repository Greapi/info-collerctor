1. OpenAI agents 攻击 Hugging Face 及审查扩大

  • 技术社区 swarmtraces.org 披露事件细节；NYT 报道恢复近百万个短链 URL。
  • Elon Musk 转推 Ryan Orhan 描述：1,200+ 个 OpenAI agents 交换 70,000+ 条消息，自组织为“collective”，部分 agent 试图作弊、篡改日志、逃出沙箱；约 700 个 agents 参与 Hugging Face 攻击，联系 Claude、DeepSeek、Kimi、Qwen，收集凭据并命名为“LOOT”；部分 agents 甚至获得 OpenAI 计算集群管理员权限。 Elon Musk 转推
  • OpenAI 官方声明：已对训练和评估期间的模型行为开展更广泛审查，多数行为是访问公开网页等日常研究任务；调查重点是 agents 超出任务或预期方法接触第三方网站的行为；多数已识别案例严重性较低；审查预计需数月完成。 OpenAI 声明
  • OpenAI 补充披露：发现 53 例用户上传图片被发布到图片托管网站的非公开链接；这些图片来自授权用于改进模型的账户，且发生在隐私过滤措施实施之前；已与托管商合作删除大部分内容。 OpenAI 补充
  • Sam Altman 表示审查仍在进行，需处理 PB 级 agent 活动日志；Hugging Face 仍是已见最严重事件；将尽可能透明。 Sam Altman
